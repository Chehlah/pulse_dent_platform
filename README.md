# PulseDent Platform

สรุปภาพรวมของเว็บแอปพลิเคชันใน repository นี้

## เว็บนี้คืออะไร?
**PulseDent Platform** (พัลส์เดนต์) เป็นเว็บต้นแบบ (Front-end Prototype) สำหรับ **แพลตฟอร์มดิจิทัลที่ทำงานร่วมกับอุปกรณ์อัจฉริยะเพื่อประเมินภาวะโพรงประสาทฟันตาย (Smart Dental Pulp Vitality Assessment Device and Platform)**

ตัวเว็บถูกพัฒนาขึ้นเพื่อจำลองการทำงานของระบบตรวจวัดและวิเคราะห์ค่าทางชีวภาพของฟัน ได้แก่:
- **อุณหภูมิ (Temperature)**
- **ชีพจร (Pulse)**
- **ระดับออกซิเจน (Oxygen Saturation)**

โดยนำค่าจาก **ฟันอ้างอิง (Reference)** มาเปรียบเทียบกับ **ฟันเป้าหมาย (Target)** เพื่อคำนวณผลต่างและประเมินระดับความเสี่ยงของภาวะโพรงประสาทฟันตาย

## ฟีเจอร์และหน้าจอหลัก (4 แท็บ)

1. **ตรวจวัด (Dashboard)**
   - **แผนผังฟัน (Dental Map):** แสดงภาพฟัน 32 ซี่ (ระบบ FDI: 11–48) แบ่งฝั่ง Upper / Lower สามารถสลับโหมดเพื่อคลิกเลือก **ฟันอ้างอิง** และ **ฟันเป้าหมาย** ได้โดยตรง
   - **หน้าจอแสดงผลและประมวลผล (Measurement):** แสดงการ์ดข้อมูลของฟันอ้างอิง ฟันเป้าหมาย ค่าผลต่าง (อุณหภูมิ, ชีพจร, ออกซิเจน) และผลประเมินความเสี่ยง พร้อมปุ่ม **รีเซ็ต** และ **บันทึกผล**

2. **ข้อมูลอ้างอิง / ควบคุมสถานการณ์จำลอง (Simulation Control)**
   - มีสถานการณ์จำลองให้เลือกทดสอบ 5 รูปแบบ เพื่อดูการตอบสนองของระบบ:
     - `ฟันปกติ`
     - `เฝ้าระวัง`
     - `เสี่ยงสูง`
     - `แนวโน้มโพรงประสาทฟันตาย`
     - `วัดไม่สำเร็จ` (จำลองกรณีอุปกรณ์อ่านค่าไม่ได้)

3. **ประวัติ (Patient Record)**
   - ตารางบันทึกผลการตรวจจำลอง (วันที่, ผู้รับการตรวจ, ฟันอ้างอิง, ฟันเป้าหมาย, ผลต่างอุณหภูมิ, ผลต่างชีพจร, ผลต่างออกซิเจน, ผลประเมิน) พร้อมปุ่ม **ล้างประวัติ**

4. **การตั้งค่า (Settings)**
   - **ข้อมูลที่แสดงหน้าหลัก (Display):** เปิด/ปิดการแสดงผลข้อมูลบนหน้า Dashboard
   - **กลุ่มฟันที่กดเลือกได้ (Tooth Groups):** เปิด/ปิดการเลือกฟันตามกลุ่ม (เช่น ฟันตัดกลาง, ฟันเขี้ยว, ฟันกราม ฯลฯ)
   - **เกณฑ์ประเมินจำลอง (Threshold):** ปรับค่าเกณฑ์ที่ใช้ตัดสินระดับความเสี่ยง และปุ่ม **คืนค่าตั้งต้น**

## สถาปัตยกรรมและเทคโนโลยี
- **Pure Front-end (Static Web):** ใช้ HTML, CSS และ Vanilla JavaScript ล้วน ไม่มีการใช้ Framework หรือ Backend API
- **การเก็บข้อมูล (Persistence):** ใช้ `localStorage` ของเบราว์เซอร์ในการบันทึกประวัติการตรวจ (`pulsedent-history`) และการตั้งค่า (`pulsedent-settings`)
- **สถานะอุปกรณ์:** แสดงสถานะการเชื่อมต่อและแบตเตอรี่จำลองบนแถบด้านบน (Topbar)
